## ServiceNow-ITSM-Network-Internet-Interruption-Problem-Management

# 📌 Project Overview
Implemented a hands-on ServiceNow Problem Management solution to investigate recurring network interruptions, perform root cause analysis, analyze related incidents, and implement corrective actions to prevent recurrence and improve service reliability.

# 🏆 Summary of Accomplishments

• Created and managed Problem Records linked to recurring network incidents.

• Performed root cause analysis (RCA) and documented findings.

• Analyzed related incidents to identify patterns and recurring issues.

• Managed Problem Tasks for investigation and resolution activities.

• Documented workarounds, root causes, and permanent solutions.

• Managed the Problem lifecycle from Identification → Investigation → Resolution → Closure.

• Linked affected incidents to the Problem record for improved ITSM visibility and tracking.
